# 🚀 TrackLet Super Admin - Quick Start Guide

## ⚡ GET STARTED IN 3 MINUTES!

---

## Step 1: Update API URL (30 seconds)

Open: `lib/src/utils/app_constants.dart`

```dart
static const String apiBaseUrl = 'http://192.168.0.106:5000';  // ← Change this to YOUR IP
```

**To find your IP:**
```bash
# Windows
ipconfig

# Look for "IPv4 Address" (e.g., 192.168.0.106)
```

---

## Step 2: Start Backend (30 seconds)

```bash
cd "D:\flutter project\TrackLet_backend_server"
node server.js
```

**Expected Output:**
```
SuperAdmin model compiled
User model compiled
MongoDB connected successfully
Server running on port 5000
```

✅ If you see this, backend is READY!

---

## Step 3: Run Super Admin App (1 minute)

```bash
cd "D:\flutter project\tracklet_super_admin"
flutter run
```

Select your device when prompted.

✅ App should open automatically!

---

## Step 4: Login (30 seconds)

App will open with login screen pre-filled:

```
Email: agha@tracklet.com
Password: 12345678
```

**Just click "Login"!** ✅

## ⚠️ TROUBLESHOOTING

### Issue: "Network Error" on login
**Fix**: Check if backend is running and API URL is correct in `app_constants.dart`

### Issue: "Connection refused"
**Fix**: Make sure your phone and PC are on same WiFi network

### Issue: Backend not starting
**Fix**: Make sure MongoDB is running (`mongod`)

### Issue: App doesn't connect to backend
**Fix**: Update `network_security_config.xml` with your IP address
